# Panificadora Santtini

Site estático (HTML/CSS/JS, sem build). Deploy na Vercel direto da raiz.

## Fotos
Coloque as fotos em `assets/photos/` com estes nomes (JPG): `hero`, `paes`, `bolos`, `coffee-break`, `sopas`, `almoco`, `cafe-colonial`, `g1` a `g6`.
Sem arquivo, o espaço mostra um placeholder; com arquivo, a foto aparece sozinha.

## Cores (em `styles.css`)
Vermelho `#E3261B`, laranja `#F28C1B`, vinho `#3A0B08`, creme `#FBF3E8`.
